The purpose of every demo is to provide a place to try and develop new features until they are ready to be put into production.

# Dev Categories Overview
 - debug: Created for a one-time or ongoing debugging of a production feature
 - concept: A new feature being tested that is not yet in production or has new features not yet in production.
 - demo: Created for internal demonstration purposes for developers working on the project.
 - experimental: Features available in production but only as an experimental feature, typically because they are not fully developed or confirmed to be in the final plan.
