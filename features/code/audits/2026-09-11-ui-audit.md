## Fixed in this audit

1. **Mobile navigation gap.** The stacked layout displayed only the selected Code pane; the shell menu exposed global routes rather than a reliable Code pane switcher. Added an accessible 44px native selector driven by the canonical `ACTIVITY_VIEWS` registry. Live phone check switched Source Control to Search successfully.
2. **Phone editor space.** Monaco's minimap consumed a material portion of the narrow viewport. Disabled only on phone breakpoints; desktop behavior retained. Verified in dark phone screenshot.
3. **False Ports count.** Failed first load rendered “0 listening ports”. It now says “Port status unavailable”, with explicit checking state before the first response. Live verification reproduced the backend 500 and confirmed the honest header.
4. **Missing Ports error capture.** Error Inspector showed zero captured errors despite the visible Ports HTTP failure. Added structured capture at the failed request, without response bodies or credentials.
5. **Run stale folder dependency.** Script discovery closed over `root` but depended only on the filesystem object. Added the folder dependency so navigating within the same sandbox rescans the chosen folder.
6. **Invisible scope.** Search now names its sandbox-wide search root; Run names the actual directory scanned for manifests.
7. **Search accessibility.** Case and regex switches now have descriptive accessible names; enclosing touch targets have a 44px phone minimum.
