# Handoffs

Forward-looking work orders, not history. **Invoke the `handoffs` skill before writing, taking over, or grooming anything in this directory** — it holds the format, the per-turn grooming rule (completed task → one bullet), and the delete-when-done rule. Rot backstop: `/handoff-cleanup`. Cross-repo: one doc per piece of work, shared system with aidream.

**No owner yet?** Unowned handoffs — from BOTH repos — are listed in [`UNASSIGNED.md`](./UNASSIGNED.md). **Taking one over: delete its row first. Leaving work behind: add its row.** No statuses, ever.
